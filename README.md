# 扣哒世界 · 未来学校（家长端首页项目）

一个可以整包上传的静态站点，不需要构建、不依赖任何框架。首页面向家长，展示四种上课方式；其中**编程自学课**与 **AI 自学课**两个大按钮已可直接跳转到完整详情页。

## 目录结构

```
未来学校/
├─ index.html            首页（未来学校）
├─ home.css              首页样式
├─ home.js               首页交互（移动端菜单、咨询二维码弹窗、滚动渐显）
├─ assets/               首页共用图片（场景图、学习地图、二维码、CoCo 图标、AI logo）
├─ self-study/           编程自学课详情页（含 faq.html 与视频素材）
├─ ai-self-study/        AI 自学课详情页（扣哒学堂网课 · 扣哒宇宙AI课）
│  └─ project/           四个可体验的项目页（桃花源寻境、几何能量站、水果词语大冒险、神秘样品侦测）
├─ 文案与内容.md          全部文案、四种课程对比、口径与合规提示、修订记录
└─ README.md             本文件
```

## 本地查看

在项目根目录启动任意静态服务器，例如：

```powershell
python -m http.server 8899
# 打开 http://127.0.0.1:8899/index.html
```

直接双击 `index.html` 也能打开，但用服务器预览更接近线上效果。

## 上线

1. 将整个 `未来学校` 目录上传到站点根目录（或子目录），保持相对路径不变。
2. 若部署在子目录（例如 `https://example.com/school/`），当前相对链接无需修改即可正常工作。
3. `self-study/assets/` 内的视频约 34 MB，GitHub 网页上传可用；单文件均小于 25 MB。

## 设计说明

- 结构与说服顺序参考 Synthesis Tutor：先替家长说出顾虑 → 给出解法 → 展示学什么 → 展示成果 → 消除风险 → 只留一个动作（先免费试）。
- 配色与两个详情页一致：深蓝 `#0f1a2b`、米白 `#faf7f0`、橙 `#ef8a3c`、金 `#f3c98b`。
- 响应式断点：1080px（折叠导航、单列）、760px（手机端单列 + 底部双按钮操作条）。
- 首页三处出现两个大按钮（首屏、四种上法卡片、结尾），移动端还有常驻底部条。
- 首页左上角使用官方「扣哒世界」logo（`assets/logo-cn.png`），后接「未来学校」；两个详情页分别使用 CodeCombat 与扣哒宇宙 logo。
- 编程自学课的关卡演示视频不显示控件，进入页面即自动静音循环播放，画面无外框。
- 编程自学课价格区为单张深色双栏卡：左栏价格与「先免费体验 8 关」，右栏 8 条权益，¥999 全页只出现一次。
